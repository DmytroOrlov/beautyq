## Chronology and supersession (read before citing)

The four detailed files are **immutable-ish chronological research snapshots**, not one mutually
consistent final document. One contains an intermediate Qdrant interpretation that a later source-level
inspection corrected; the snapshots are preserved as-is and are not rewritten.

- `raw-trace-test.md`, `raw-qdrant-framework.md` — first-pass historical harvests.
- `HANDOFF.md` — subsequent current-source reconciliation; still uses provisional, pre-final candidate IDs.
- `QDRANT-VALUE-FORENSIC.md` — later source-level forensic correction for Qdrant value semantics.

Where `raw-qdrant-framework.md` (or any earlier harvest) describes QP18/QP19 using "improvement" language,
`QDRANT-VALUE-FORENSIC.md` **supersedes** that interpretation: QP18/QP19 prove structural
append/no-worsening, not relevance/product value. Final Feature 004 candidate IDs, dispositions, human
verdict, and concise conclusions are owned by `../../decision-record.md` and `../../research.md`.

Reading precedence for conclusions:

1. current source/tests/normative docs — current system truth;
2. `../../decision-record.md` — final Feature 004 decision/verdict;
3. `../../research.md` — final concise reconciliation conclusions;
4. `QDRANT-VALUE-FORENSIC.md` — where it corrects earlier Qdrant historical interpretation;
5. `HANDOFF.md` and the raw harvests — detailed chronological evidence.

This does not make the archaeology normative; it prevents treating an earlier intermediate finding as the
final result.
